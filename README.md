# Aljawhrah Farm – tools

| Folder | What it is |
|---|---|
| [`tiktok-hq/`](tiktok-hq/) | **TikTok HQ** – local tool that prepares a video so TikTok serves the uploaded file as-is ("Original" quality, no re-compression). Ready-made desktop app for Windows/macOS on the [Releases](https://github.com/wlyx69/Aljawhrah-farm/releases/latest) page (ffmpeg inside, nothing to install); or run the single Python file with ffmpeg. |

See each folder's README for usage.
