هذا الجهاز ينقصه مكوّن Microsoft Edge WebView2

الواجهة الحديثة تحتاج مكوّن WebView2 (موجود تلقائيًا في Windows 11 وأغلب أجهزة Windows 10). على هذا الجهاز ما لقيناه، فالبرنامج فتح بمحرك Internet Explorer القديم اللي ما يقدر يعرضها.

الحل (مرة وحدة): نزّل وثبّت "WebView2 Runtime" من صفحة مايكروسوفت الرسمية ثم افتح البرنامج من جديد:
developer.microsoft.com/microsoft-edge/webview2

بديل مؤقت: شغّل البرنامج بالواجهة الكلاسيكية: افتح Command Prompt في مجلد البرنامج واكتب TikTokHQ-windows.exe --classic

This machine has no Microsoft Edge WebView2 runtime, so the app opened with the legacy Internet Explorer engine. Install the WebView2 Runtime from the link above, or run TikTokHQ-windows.exe --classic for the classic window.
